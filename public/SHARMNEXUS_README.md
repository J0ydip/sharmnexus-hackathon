## 🎨 Customization Guide

### Change Brand Colors
Edit `shramnexus-landing.css`, top of file:
```css
:root {
    --primary: #001a4d;        /* Change to your color */
    --secondary: #7c3aed;      /* Change to your accent */
    --success: #10b981;        /* Change to your success color */
}
```

### Change Brand Name
Edit `shramnexus-landing.html`:
```html
<span>ShramNexus</span>  <!-- Line ~27, navbar logo -->
```

### Add/Remove Services
Edit `shramnexus-landing.html`, service categories section:
```html
<div class="service-card">
    <div class="service-icon">⚡</div>
    <h3>Electrical</h3>
    <p>Repairs, fittings & installation</p>
</div>
```

### Change Testimonials
Edit `shramnexus-landing.html`, testimonials section:
```html
<div class="testimonial-card">
    <div class="testimonial-rating">⭐⭐⭐⭐⭐</div>
    <p class="testimonial-text">"Your feedback here"</p>
    <div class="testimonial-author">Name</div>
    <div class="testimonial-service">Service Type</div>
</div>
```

### Update Worker Demo Data
Edit `shramnexus-landing.html`, search for "Raj Kumar" and change:
- Name
- Title
- Rating
- Distance
- Metrics

### Connect to Backend APIs
Edit `shramnexus-landing.js`, add fetch calls:
```javascript
// Example: Fetch real workers
async function getRealWorkers() {
    const response = await fetch('/api/workers');
    return response.json();
}
```

### Enable Translation
Add translation library (i18next, react-i18n, etc.) and connect to language selector:
```javascript
function initLanguageSelector() {
    const languageSelect = document.getElementById('languageSelect');
    languageSelect.addEventListener('change', function(e) {
        // Integrate with translation library
        changeLanguage(e.target.value);
    });
}
```

## 🆘 Troubleshooting

### Images Not Loading
- Check file paths
- Ensure images are in correct folder
- Use complete URLs for external images

### Animations Not Working
- Check browser DevTools Console for errors
- Ensure CSS and JS files are linked correctly
- Try a different browser

### Mobile Menu Not Opening
- Check if hamburger button is visible (use DevTools)
- Ensure CSS media query is correct
- Try hard refresh (Ctrl+Shift+R)

### Counters Not Animating
- Scroll to trust section
- Check if scroll event is firing
- Open console to see any errors
